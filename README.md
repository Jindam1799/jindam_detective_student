# 한자어 탐정단 🔍

우리말 속 한자를 찾으면 중국어가 툭! — 초등 저학년용 한자어·중국어 탐정 게임 (진담중국어)

## 구성
- 사건 1 우리 학교 · 사건 2 내 생일 · 사건 3 동네 간판 (활동지 1장 = 사건 1개)
- 사건마다 미션 5개 → 다 풀면 **도장 카드** → 선생님 비밀번호로 「선생님 확인」 도장
  1. 소리 탐정 — 중국어 소리 듣고 우리말 고르기
  2. 한자 뜻 찾기 — 중국 한자 + 힌트 단어 보고 뜻(훈음) 고르기, 번체→간체 보여 주기
  3. 한자어 탐정 — 장면마다 한자어 4개 콕! (순우리말·외래어는 X)
  4. 따라 읽고 쓰기 — 듣고 따라 말하기 → 田자 칸에 손가락으로 따라 쓰기
  5. 1초 반응 — 질문 듣고 대답 고르기, 3초 안이면 「툭!」, 정답 뒤 "따라 말해요"
- 틀린 문제는 2문제 뒤에 다시 나옴. 실수 0개 ★3 / 1~2개 ★2 / 3개 이상 ★1

## 파일
| 파일 | 내용 |
|---|---|
| index.html | 화면 뼈대 + 직접 그린 SVG 그림 (마스코트 툭이, 장소 그림 19종) |
| style.css | 디자인. 화면 크기에 맞춰 글자 크기가 자동 조절 → 스크롤 없음 |
| data.js | **수업 내용** (단어·한자·장면·질문) + 선생님 비밀번호 `TEACHER_PIN` |
| app.js | 게임 동작 |
| sw.js / manifest.webmanifest / icons/ | 홈 화면 앱·오프라인 |

## GitHub Pages 올리기
1. 새 저장소 만들기 (예: `jindam_hanja_tamjeong`)
2. 이 폴더 안의 파일을 **모두** 저장소 맨 위(루트)에 올리기 (`.nojekyll` 포함)
3. Settings → Pages → Branch `main` / `/(root)` → Save
4. 주소: `https://아이디.github.io/저장소이름/`

## 수정할 때
- 비밀번호: data.js 맨 위 `TEACHER_PIN` (공개 저장소라 소스에서 보이므로 학생에게 링크만 주세요)
- 새 활동지: data.js `LESSONS`에 같은 모양으로 사건 하나 추가
- 파일을 고친 뒤에는 sw.js의 `CACHE` 이름 끝 날짜를 바꾸면 학생 기기도 새 버전으로 바뀜
